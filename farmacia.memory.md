# Memoria del proyecto · farmacia (UCI/UCPA)

- Contexto: UCI/UCPA de un hospital (Mendoza, Argentina). Objetivo: repo GitHub sobre el proceso de pedido de farmacia, control de stock y uso de insumos en sala, con app estática publicable en GitHub Pages (un "link" usable fuera del sistema, con salida copiable/pegable hacia el sistema o Excel).
- App actual: `index.html` = SPA "FARMACIA 2.0 - DISTEL DIEGO", pestañas Médico / Enfermería / Farmacia / Finalizadas. Sin persistencia (estado en memoria; se pierde al recargar), sin stock, sin generación de pedido. Existen 8 versiones `index*.html`; la vigente es `index.html`.
- Vademécum: `vademecum.csv` (5.174 filas: codigo, tipo/presentación, nombre). Se regeneró `data/vademecum.json` (501 KB, formato `{codigo,tipo,nombre}`) para que la app lo cargue; el `vademecum.json` de la raíz está mal convertido (todas las filas con las mismas claves) y no debe usarse.
- `Codigo` es la clave compartida entre vademécum, `anual UTIA.xlsx`, `PM UCPA.xlsx`, `mon UCPA.xlsx` y `UCIA.xlsx`.
- Modelo de stock propio del usuario (columnas de `UCIA.xlsx` / fórmulas en `UCIA FORMULA.xlsx`, 422 ítems de UCI A): D = C/365 (consumo diario); E = D·0,6 (consumo diario real 60%); F = 1,65·(0,3·D)·√1 (desvío); G = D·1 + F (stock seguridad); H = G + D·2 (punto de pedido); I = H + E·2 (stock objetivo); J = ROUNDUP(I) (stock final redondeado).
- `anual UTIA.xlsx`: consumo anual por ítem (422). `PM UCPA.xlsx` (273) y `mon UCPA.xlsx` (249): catálogos/listas por servicio (significado exacto a confirmar con el usuario).
- Base teórica: `pagliarulo-fce.pdf` — tesis 2018 "Proceso de gestión de stock en farmacia hospitalaria", Hospital Universitario de Mendoza: normativa AAFH, PP = SS + PE·DM, modelo de Wilson, ABC, rotación/cobertura, dosis unitaria.
- Investigación archivada: `docs/03-grandes-hospitales.md` (flujo pedido→validación→entrega→consumo→devolución, modelos de reposición, sistemas open source, modelo de datos mínimo, KPIs, codificación y trazabilidad ANMAT/GS1; fuentes al pie, con límites marcados).
- Repo: https://github.com/diegodistel88-glitch/FARMACIA2.0DISTEL (público, Pages en `https://diegodistel88-glitch.github.io/FARMACIA2.0DISTEL/`). Local: sin credenciales GitHub (no `gh`, sin helper), por lo que los commits no se pueden pushear sin token o subida manual.
- Historial local: commit `49366cf` (v2: título, vademécum corregido, README, MIT, docs) y `ebbb637` (v3.0: pestaña Insumos con stock/kardex/pedido, persistencia localStorage del stock, respaldo JSON, tests).
- v3.0 implementado en `index.html`: pestaña Insumos (buscador sobre VADEMECUM, stock con movimientos ingreso/consumo/devolución/ajuste, punto de pedido y objetivo editables, alertas, pedido sugerido con copiar texto/TSV/CSV/imprimir, exportar/importar respaldo `{app:'gestion-hospitalaria',schema:3,items}`). Persiste en localStorage `gh:v3:stock`. Test de humo: `npm install --no-save jsdom && node scripts/test-app.js` (13/13 OK).
